# dbt + Metabase analytics

Deploy a small, complete analytics stack: scheduled dbt transformations, a ready-to-use Metabase dashboard, and separate PostgreSQL databases for Metabase state and warehouse data.

The first boot creates a generated administrator, seeds and tests an example dbt model, connects Metabase to the warehouse, and adds a working question and dashboard. Replace the example project with your own models and adjust the daily run interval when you're ready.

All data services stay private. Metabase is the only public service, credentials are generated by Railway, anonymous tracking and sample content are disabled, and both PostgreSQL services use persistent 5 GB volumes.
